# MITM via ARP Spoofing — blog + paper

Static site with a write-up of my MITM/ARP-spoofing paper and a link to the full PDF.

**Live site:** enable GitHub Pages, then it will be at
`https://muraliikrishnant.github.io/MITM_AttackArpPoison/`

**Paper:** [`assets/MitM_Attack_Arp_Poisoning_FinalReport.pdf`](assets/MitM_Attack_Arp_Poisoning_FinalReport.pdf)

## Enable GitHub Pages
1. Go to **Settings → Pages** on this repo.
2. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
3. Select branch `main` and folder `/ (root)`. Save.
4. Wait ~1 minute, then open the URL above.
